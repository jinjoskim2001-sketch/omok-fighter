# 돌주먹 — 오목 파이터

친구랑 아이폰 한 대로(또는 CPU와) 두는 **캐릭터 대전 오목**입니다. 링크를 열고 홈 화면에
추가하면 아이폰에서 앱처럼 쓰는 웹 앱이에요. 캐릭터 여덟을 골라 붙고, 이기면 캐릭터마다
고유한 승리 모션이 나옵니다.

- 주소: https://jinjoskim2001-sketch.github.io/omok-fighter/ (끝의 `/`까지 공유하세요)
- 정적 파일만 씁니다. 프레임워크, 빌드 단계, 서버, 외부 스크립트, 외부 글꼴이 없습니다.
- 한 번 열고 나면 비행기 모드에서도 됩니다(서비스 워커가 모든 파일을 기기에 담아 둡니다).
- 저장은 기기 안(localStorage)에만 남습니다. 수집하는 정보는 없습니다.
- 지인끼리 쓰는 비상업 프로젝트입니다.

## 친구에게 보내는 설치 방법

링크를 보내고 아래처럼 안내하면 됩니다. 앱이 처음 열릴 때도 같은 안내 화면이 나옵니다.

1. **Safari**에서 링크를 엽니다.
2. **공유**를 엽니다.
   - iOS 26: 주소창 옆 **···** → **공유**
   - iOS 27: **주소창을 꾹** 누르고 → **공유** (주소창 왼쪽 메뉴 버튼으로도 열려요)
3. 목록을 내려서 **홈 화면에 추가**를 누릅니다(안 보이면 맨 아래 **동작 편집**).
4. **웹 앱으로 열기**를 켠 채로 **추가**를 누릅니다.
5. 이제부터는 홈 화면의 **돌주먹** 아이콘으로 엽니다.

- **카카오톡에서 링크를 눌렀을 때**: 카카오톡 안의 브라우저에서는 홈 화면에 추가할 수 없어서
  "Safari에서 열어야 설치할 수 있어요" 화면이 나오고, 잠깐 뒤 Safari로 넘겨 줍니다. 안 넘어가면
  오른쪽 아래 **공유 버튼 → Safari로 열기**를 누르거나, 화면의 **주소 복사**로 주소를 복사해
  Safari 주소창에 붙여 넣으면 됩니다. 인스타그램·스레드·페이스북(오른쪽 위 ··· → 외부 브라우저),
  라인, 네이버 앱도 같은 식으로 안내합니다.
- 아이콘으로 열었는데도 안내 화면이 보이면 "웹 앱으로 열기"가 꺼진 채 추가된 것입니다.
  아이콘을 지우고 켠 채로 다시 추가하세요.
- 설치하지 않고 **설치 없이 해보기**로 Safari 탭에서 둘 수도 있지만, 탭에서 쌓은 전적은 설치한
  앱으로 옮겨지지 않고 오래 안 열면 사라질 수 있어요.
- 안드로이드는 안내 화면 없이 바로 열리고, 크롬이 설치를 제안하면 "앱으로 설치" 버튼이 뜹니다.

## 하는 법

- **둘이서 한 폰으로**(2P) 또는 **CPU랑**(쉬움·보통·어려움). 단판, 3판 2선승(기본), 5판 3선승,
  7판 4선승 중에서 고릅니다.
- 15×15 판, **흑이 먼저** 둡니다. 가로·세로·대각선으로 **정확히 다섯 개**를 먼저 이으면 그 판을
  이깁니다(K.O.!).
- 칸이 작아서 한 번 탭하면 **조준**, 같은 자리를 한 번 더 탭하면 **착수**입니다. 꾹 누르거나 끌면
  돋보기가 나와요. 설정에서 "한 번 탭하면 바로 착수"로 바꿀 수 있습니다.
- **쌍삼(3-3) 금지**: 한 수로 열린 3을 두 개 동시에 만드는 자리는 흑·백 모두 둘 수 없습니다.
  누르면 빨간 X와 함께 "쌍삼 금지!"가 떠요(띈 3도 3으로 칩니다). 4-4와 4-3은 됩니다.
- **장목**: 여섯 개 이상 이은 줄은 승리가 아닙니다(설정에서 "6목 이상도 승리"로 바꿀 수 있어요).
  다섯을 만들면서 쌍삼이 되는 수는 다섯이 우선이라 이깁니다.
- 판이 꽉 차거나 둘 수 있는 칸이 없으면 무승부, 다음 판은 색을 바꿉니다. 2판째부터는 진 사람이
  흑(설정에서 "번갈아"로 변경)입니다.
- 무르기(2P는 상대가 허락해야 해요), 한 수 시간제한, 기권은 매치 설정과 일시정지 메뉴에 있습니다.
- 앱을 닫거나 전화가 와도 매 수마다 저장되니 다음에 **이어하기**로 계속하면 됩니다.

## 개발

```sh
python3 tools/serve.py              # http://localhost:8791/?play=1  (캐시 없는 개발 서버)
node --test tests/                  # 전체 테스트 (tests/index.js 가 모든 *.test.js 를 불러옵니다)
node --test tests/integration.test.js   # 파일 하나만
```

- `?play=1` 은 설치 안내를 건너뛰고 바로 게임을 엽니다. `?gate=install|escape` 는 안내 화면을
  강제로, `?shot=<상태>` 는 스크린샷용 고정 화면을 엽니다(목록은 `js/debug.js` 맨 위).
- localhost 에서는 서비스 워커를 등록하지 않습니다(고친 파일이 바로 보이도록). 오프라인 동작은
  `?play=1&sw=1` 로 확인합니다.
- 설치 안내 화면만 보려면 `tools/demo-gate.html?mode=install&safari=26`(또는 `27`),
  `tools/demo-gate.html?mode=escape&app=kakaotalk`, `&ingame=1`(메뉴에서 연 안내), `&audit=1`
  (터치 영역·넘침 점검), `?mode=notice&failed=1`(불러오기 실패 화면).

### 스크린샷 (Playwright)

```sh
node tools/shot.mjs "?play=1&shot=battle" /tmp/battle.png 393 852 --standalone
node tools/shot.mjs "/" /tmp/gate.png 375 667 --ua safari26          # 실제 첫 화면(설치 안내)
node tools/shot.mjs "tools/demo-gate.html?mode=escape&app=kakaotalk" /tmp/kakao.png --ua kakao
PLAYWRIGHT_BROWSERS_PATH=<webkit 이 있는 폴더> node tools/shot.mjs "/" /tmp/wk.png --webkit
```

- 저장소를 임의의 포트로 직접 띄우고, 지정한 크기(CSS px)를 3배 해상도로 찍습니다. 콘솔 에러,
  페이지 에러, 실패한 요청을 모두 출력합니다. 옵션: `--standalone`(홈 화면 앱 흉내),
  `--ua safari26|safari27|kakao|insta|chrome-ios|android`, `--webkit`, `--wait <ms>`, `--full`,
  `--dpr <n>`, `--offline`(한 번 연 뒤 네트워크를 끊고 다시 열기, `?sw=1` 과 함께).

### 그림과 글꼴

```sh
node tools/make_icons.mjs --preview /tmp/icons.png   # icons/*.png 다시 만들기 (+ 미리보기 한 장)
python3 tools/make_font.py                           # fonts/bhs.woff2 다시 만들기
```

- 아이콘은 `tools/make_icons.mjs` 안의 벡터 그림을 Chromium 으로 그려 Pillow 로 정확한 크기의
  불투명 PNG 로 저장합니다(광택 흑돌·백돌이 부딪히고, 흑돌이 빨간 복싱 글러브로 한 방 — 돌주먹).
- 글꼴은 Black Han Sans 에서 실제로 화면에 쓰는 글자만 남긴 서브셋입니다. **화면 문구를 바꾸면
  `make_font.py` 를 다시 돌리세요.** 빠진 한글이 있으면 통합 테스트가 실패합니다.
- `tools/` 와 `tests/`, `docs/` 는 개발용이며 앱이 불러오지 않습니다(오프라인 캐시에도 넣지
  않습니다). `tools/dev/` 는 git 에서 제외된 작업 폴더입니다.

## 배포 (GitHub Pages)

저장소 `jinjoskim2001-sketch/omok-fighter`, Pages 는 `main` 브랜치 루트에서 배포합니다.

1. `sw.js` 맨 위의 `VERSION` 을 올립니다. 예: `omok-v1` → `omok-v2`
2. `js/main.js` 의 `VERSION` 도 똑같이 맞춥니다(타이틀 구석과 설정 화면의 "버전"에 보이는 값).
   두 값이 다르면 테스트가 실패합니다.
3. 파일을 더하거나 지웠다면 `sw.js` 의 `PRECACHE` 목록도 맞춥니다. 통합 테스트가 실패하면서
   붙여 넣을 목록을 그대로 출력해 줍니다.
4. `node --test tests/` 가 모두 통과하면 커밋하고 `main` 에 푸시합니다.

버전을 올려야 이미 설치한 사람의 앱이 새 파일로 바뀝니다. 새 버전은 앱을 연 뒤 뒤에서 받아 두고,
대국·연출·열린 메뉴를 끊지 않도록 화면이 한가할 때(타이틀·메뉴)나 다음에 앱으로 돌아올 때 한 번
새로고침되며 적용됩니다. 진행 중인 매치는 그 전에 저장되니 이어하기로 계속됩니다. 받는 중에
파일 하나라도 실패하면 이전 버전이 그대로 남고 다음에 다시 시도합니다. **`sw.js` 파일 이름은 절대
바꾸지 않습니다**(Safari 는 스크립트가 404 인 서비스 워커를 지워 버립니다).

같은 주소(`jinjoskim2001-sketch.github.io`)에 다른 앱(`/pumal/`)이 있어서, 저장 키는 모두
`omok.`, 캐시 이름은 모두 `omok-` 로 시작합니다. 서로의 데이터를 건드리지 않습니다.

아이콘과 앱 이름은 iOS 가 설치할 때 한 번만 읽습니다. 바꾸면 이미 설치한 사람에게는 반영되지
않으니 첫 공유 전에 확정하세요. 링크 미리보기 그림(`icons/og-800x400.png`)을 바꿨다면
`index.html` 의 `og:image` 주소 끝 `?v=` 숫자도 올립니다.
